# LibreUSOS

Unofficial, open-source client for USOS, the university system used at Polish universities. Not affiliated with any university or with the USOS developers. Built in, for now: the Silesian University of Technology.

## Features

- Android app: today's classes, timetable, grades per term, course tests, home-screen widget, background sync, offline cache. Polish and English.
- `usos` command-line tool: login, timetable, grades, tests, offline sync.
- Login through the browser (OAuth 1.0a). The app never sees your password.

## Get it

Android APK and CLI builds are on the [releases page](https://gitlab.com/libreusos/LibreUSOS/-/releases).
